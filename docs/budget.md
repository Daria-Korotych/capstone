# Бюджет M2

Pricing Calculator (режим 24/7): https://calculator.aws/#/estimate?id=74d7e3e763cded6b409a39b407076335e9cc2dd2 — Total monthly $28.60 (Amazon EC2 $25.60, Amazon CloudWatch $3.00), збігається з розрахунком нижче. Режим сесій рахується з тих самих цін за 60 год/міс.

## Припущення

- M2 = 3 × `t3.micro` (2 vCPU, найдешевший дозволений тип, див. [quotas.md](quotas.md)), `us-east-1`, Linux, Shared tenancy, On-Demand.
- Режим 24/7 = 730 год/міс.
- Режим сесій: N = 60 год/міс (20 сесій × 3 год; 20 сесій на місяць — припущення).
- Диски: 3 × gp3 по 8 GiB; томи зберігаються між сесіями, тому EBS тарифікується за GB-місяць повністю в обох режимах.
- Передача даних назовні: 10 GB/міс, перший ступінь ціни; однаково в обох режимах.
- Моніторинг: базові метрики EC2 безкоштовні; 10 кастомних метрик CloudWatch (повна ціна в обох режимах, без пропорційного зменшення).
- Free tier не враховано.
- Public IPv4: інстанси M2 стоять у private-підмережах, публічних адрес немає, вартість 0. Якби були: $0.005 за адресу за годину.
- NAT Gateway у M1 немає; якщо M2 його додасть, це нова стаття (не враховано).
- Оцінка не включає шлях клієнтського входу й виходу інстансів (ALB / NAT / public IPv4). Порядок величини за приблизними тарифами us-east-1: NAT Gateway ≈ $0.045/год ≈ $2.70 за 60 год сесій (≈ $33 при 24/7), ALB ≈ $0.0225/год + LCU. Рішення й розрахунок — у M2 з окремим ADR; висновок про режим сесій не змінюється.

## Оцінка за місяць

| Стаття | 24/7 (730 год) | Сесії (60 год) |
|---|---|---|
| 3 × `t3.micro` | 3 × 730 × 0.0104 = $22.776 | 3 × 60 × 0.0104 = $1.872 |
| 3 × gp3 8 GiB | 3 × 8 × 0.08 = $1.92 | $1.92 |
| 10 GB data transfer out | 10 × 0.09 = $0.90 | $0.90 |
| 10 кастомних метрик CloudWatch | 10 × 0.30 = $3.00 | $3.00 |
| Public IPv4 | $0 | $0 |
| **Разом** | **$28.60** (28.596) | **$7.69** (7.692) |
| Кредитна стеля | $20 | $20 |
| Різниця (стеля − оцінка) | −$8.60 (перевищує) | +$12.31 (запас) |

Оцінка трафіку консервативна: AWS не тарифікує перші 100 GB вихідного трафіку в інтернет на місяць, тож фактично ця стаття для M2 = $0.

Стеля $20 — загальний кредит пісочниці, а не місячний ліміт; витрати накопичуються. Сесія триває 3 год, тож режим 24/7 у пісочниці все одно неможливий — він показує верхню межу для порівняння.

## Що урізати першим (24/7)

1. Години інстансів: самі лише $22.78 вже перевищують $20, тож без скорочення годин (тобто переходу до режиму сесій) 24/7 не вкладається, скільки б інших статей не прибрали.
2. Кастомні метрики: $3.00, залишити лише базові метрики EC2 (оцінка падає до $25.60, все одно вище стелі).
3. Data transfer: $0.90, тримати трафік усередині VPC.
4. Диски: $1.92, видаляти томи між сесіями (після цього перераховується також режим сесій).

Режим сесій вкладається з запасом $12.31, нічого урізати не потрібно.
